# Ridge

Equal-vote forecast desk for Berowra Heights, NSW (2082), and any other Australian place you search.

Every live global model gets one vote. The headline temperature is the median. The mean is shown when a hot or cold tail pulls it. Dissenters stay in the range. Rain chance is the average of each ensemble's own probability, so a 51-member set cannot outvote a smaller one.

Not a Bureau of Meteorology warning service. If a warning is out, the warning wins.

```bash
npm install
npm run dev
```
